# Chairside restock assistant demo

A clickable, responsive front-end sample showing how a dental clinic could review a proposed restock order. It uses sample prices and order history. No supplier is contacted, and no order is placed.

Open `index.html` to try the order review and demo confirmation screens. The flagged anaesthetic line requires a clinic decision before Send.
